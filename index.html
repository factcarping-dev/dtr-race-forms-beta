HOW TO USE

1. Select the circuit, then open a form. Add a vehicle reference inside a car-specific form if needed.

2. Enter the checks and measurements, add photos and sign.

3. Tap Save to archive to store a record in this browser.

4. Tap Print / Save PDF to use the iPad's built-in PDF workflow.

5. Use Export backup in the archive to save a JSON copy of your demo records.

Important: This is a standalone prototype. No background email delivery, cloud sync, or guaranteed long-term storage. Do not use it as the sole record for safety-critical inspections.
